## Implementation Details

### MediaLoader Component Structure

```tsx
// webapp/src/components/content/mediaLoader/mediaLoader.tsx
import React from 'react'
import {useIntl} from 'react-intl'
import CompassIcon from '../../../widgets/icons/compassIcon'
import './mediaLoader.scss'

type Props = {
    isLoading: boolean
    error?: string | null
    onRetry?: () => void
    children: React.ReactNode
    className?: string
}

const MediaLoader = (props: Props): JSX.Element => {
    const intl = useIntl()
    const {isLoading, error, onRetry, children, className} = props

    return (
        <div className={`MediaLoader ${className || ''}`}>
            {isLoading && (
                <div className='MediaLoader__loading'>
                    <div className='MediaLoader__spinner'/>
                    <span className='MediaLoader__loading-text'>
                        {intl.formatMessage({
                            id: 'MediaLoader.loading',
                            defaultMessage: 'Loading...',
                        })}
                    </span>
                </div>
            )}
            {error && !isLoading && (
                <div className='MediaLoader__error'>
                    <CompassIcon icon='alert-outline' className='MediaLoader__error-icon'/>
                    <span className='MediaLoader__error-text'>{error}</span>
                    {onRetry && (
                        <button
                            className='MediaLoader__retry-button'
                            onClick={onRetry}
                            type='button'
                        >
                            <CompassIcon icon='refresh'/>
                            {intl.formatMessage({
                                id: 'MediaLoader.retry',
                                defaultMessage: 'Retry',
                            })}
                        </button>
                    )}
                </div>
            )}
            {!isLoading && !error && children}
        </div>
    )
}

export default MediaLoader
```

## Potential Pitfalls / Edge Cases

1. **Cache busting on retry**: The browser may cache failed requests. Using `retryCount` in the `key` prop of the element forces a remount, but for the async fetch in useEffect, we may need to add a cache-busting query parameter to the URL.

2. **Race conditions**: If user retries quickly, old fetch operations may complete after new ones start. Consider using an AbortController or tracking the current request.

3. **Image already loaded**: The `img` element's `onLoad` event fires separately from our data fetch. Need to coordinate both loading states.

4. **Archived files**: Must preserve existing behavior for archived file detection (check `fileInfo.archived`).

5. **Layout stability**: The loading placeholder must maintain similar dimensions to the loaded content to prevent layout shift.

6. **YouTube/external videos**: These don't go through octoClient and load differently. They should not show our loading state (they have their own).

7. **Component remounting**: When using `key={retryCount}`, the entire img element remounts. Ensure event handlers still work.
