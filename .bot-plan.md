# AWS Resources and Costs Explorer Plugin — Implementation Plan

## Overview

This document outlines the complete implementation plan for the AWS Resources and Costs Explorer Mattermost plugin. The plugin creates a right-hand sidebar (RHS) panel that displays AWS account resources grouped by service category and a cost dashboard showing monthly costs with period-over-period comparison.

**Current Status**: The plugin is ALREADY FULLY IMPLEMENTED. This plan documents the existing implementation as a reference for understanding the codebase patterns and potential future enhancements.

### 2. Server-Side Patterns

#### 2.1 Plugin Main Structure (`server/plugin.go`)

**Pattern**: Plugin lifecycle management
```go
type Plugin struct {
    plugin.MattermostPlugin
    configurationLock sync.RWMutex
    configuration     *configuration
    server            *plugin.API
    logger            *plugin.Logger
    awsClient         *aws.Client
    api               *api.API
}

func (p *Plugin) OnActivate() error {
    p.server = p.API
    p.logger = &p.Logger
    if err := p.OnConfigurationChange(); err != nil {
        return err
    }
    p.api = api.NewAPI(p)
    return nil
}

func (p *Plugin) ServeHTTP(c *plugin.Context, w http.ResponseWriter, r *http.Request) {
    router := mux.NewRouter()
    p.api.RegisterRoutes(router)
    router.ServeHTTP(w, r)
}
```

**Key Points**:
- Thread-safe configuration with `sync.RWMutex`
- Separation of concerns: API layer, AWS client layer
- All HTTP requests routed through `mux.Router`

#### 2.2 Configuration Management (`server/configuration.go`)

**Pattern**: Secure credential handling
```go
func (p *Plugin) OnConfigurationChange() error {
    mmconfig := p.server.GetConfig()

    accessKeyID := ""
    if key, ok := mmconfig.PluginSettings.Plugins[PluginName]["awsaccesskeyid"].(string); ok {
        accessKeyID = key
    }

    secretKey := ""
    if secret, ok := mmconfig.PluginSettings.Plugins[PluginName]["awssecretaccesskey"].(string); ok {
        secretKey = secret
        p.logger.Debug("AWS secret key loaded from config", mlog.Int("keyLength", len(secretKey)))
    }

    configuration := &configuration{
        AWSAccessKeyID:     accessKeyID,
        AWSSecretAccessKey: secretKey,
        AWSRegion:          region,
    }

    p.setConfiguration(configuration)
    return nil
}
```

**Security Practices**:
- Secret key length logged (not the key itself)
- Configuration keys accessed case-insensitively
- Thread-safe getter/setter with RWMutex

#### 2.3 API Route Handlers (`server/api/api.go`)

**Pattern**: RESTful API with authentication
```go
func (a *API) RegisterRoutes(r *mux.Router) {
    r.HandleFunc("/aws/resources", a.handleGetAWSResources).Methods("GET")
    r.HandleFunc("/aws/costs", a.handleGetAWSCosts).Methods("GET")
}

func (a *API) handleGetAWSResources(w http.ResponseWriter, r *http.Request) {
    // 1. Authenticate user
    userID := r.Header.Get("Mattermost-User-ID")
    if userID == "" {
        a.errorResponse(w, r, model.NewErrUnauthorized("Unauthorized"))
        return
    }

    // 2. Validate configuration
    config := a.plugin.getConfiguration()
    if config.AWSAccessKeyID == "" || config.AWSSecretAccessKey == "" {
        a.errorResponse(w, r, model.NewErrBadRequest("AWS credentials not configured"))
        return
    }

    // 3. Fetch data
    resources, err := a.plugin.GetAWSResources()
    if err != nil {
        a.plugin.logger.Error("Failed to get AWS resources", mlog.Err(err))
        a.errorResponse(w, r, err)
        return
    }

    // 4. Return response
    data, _ := json.Marshal(resources)
    jsonBytesResponse(w, http.StatusOK, data)
}
```

**Best Practices**:
- Always authenticate via `Mattermost-User-ID` header
- Validate credentials before making AWS API calls
- Log errors before returning
- Use custom error types for proper HTTP status codes

#### 2.4 AWS Client Integration (`server/aws/client.go`)

type Client struct {

func NewClient(region, accessKey, secretKey string) (*Client, error) {
    cfg, err := config.LoadDefaultConfig(context.TODO(),
        config.WithRegion(region),
        config.WithCredentialsProvider(credentials.NewStaticCredentialsProvider(accessKey, secretKey, "")),

        config:    cfg,
        region:    region,
        accessKey: accessKey,

    _, err := client.GetCallerIdentity(context.TODO(), &sts.GetCallerIdentityInput{})
    return err

- Static credentials provider (plugin provides credentials, not IAM roles)
- Credential verification via STS GetCallerIdentity

#### 2.5 Resource Fetching Pattern (`server/aws/resources.go`)

**Pattern**: Service-specific resource enumeration
```go
func (c *Client) GetEC2Instances() ([]EC2Instance, error) {
    client := c.GetEC2Client()
    resp, err := client.DescribeInstances(context.TODO(), &ec2.DescribeInstancesInput{})
    if err != nil {
        return nil, err
    }

    var instances []EC2Instance
    for _, reservation := range resp.Reservations {
        for _, instance := range reservation.Instances {
            state := "unknown"
            if instance.State != nil {
                state = string(instance.State.Name)
            }
            instances = append(instances, EC2Instance{
                ID:    aws.ToString(instance.InstanceId),
                Type:  string(instance.InstanceType),
                State: state,
                AZ:    aws.ToString(instance.Placement.AvailabilityZone),
            })
        }
    }
    return instances, nil
}

func (c *Client) GetAllResources() ([]model.ResourceGroup, error) {
    var groups []model.ResourceGroup

    // Fetch resources for each service
    ec2Instances, err := c.GetEC2Instances()
    if err == nil && len(ec2Instances) > 0 {
        resources := make([]model.Resource, len(ec2Instances))
        for i, inst := range ec2Instances {
            resources[i] = model.Resource{
                ID:    inst.ID,
                Type:  inst.Type,
                State: inst.State,
                Details: map[string]interface{}{
                    "availability_zone": inst.AZ,
                },
            }
        }
        groups = append(groups, model.ResourceGroup{
            Service:   "EC2",
            Count:     len(ec2Instances),
            Resources: resources,
        })
    }

    // Repeat for S3, Lambda, RDS, EFS, ELB, ECS...
    return groups, nil
}
```

**Best Practices**:
- Each service has dedicated fetcher method
- Errors handled gracefully (continue on individual service failures)
- Resource details in flexible `map[string]interface{}`
- Only add groups for services with resources

#### 2.6 Cost Explorer Integration (`server/aws/costs.go`)

**Pattern**: Month-over-month cost comparison
```go
func (c *Client) GetCosts() ([]model.CostData, error) {
    client := c.GetCostExplorerClient()

    now := time.Now().UTC()

    // Calculate date ranges
    lastMonthStart := time.Date(now.Year(), now.Month()-1, 1, 0, 0, 0, 0, time.UTC)
    lastMonthEnd := lastMonthStart.AddDate(0, 1, -1)

    prevMonthStart := lastMonthStart.AddDate(0, -1, 0)
    prevMonthEnd := lastMonthEnd.AddDate(0, -1, 0)

    // Fetch costs for both periods
    lastMonthCosts, err := c.getCostsForPeriod(client, lastMonthStart, lastMonthEnd)
    if err != nil {
        return nil, err
    }

    prevMonthCosts, err := c.getCostsForPeriod(client, prevMonthStart, prevMonthEnd)
    if err != nil {
        return nil, err
    }

    // Calculate delta
    var results []model.CostData
    for service, currentAmount := range lastMonthCosts {
        prevAmount := prevMonthCosts[service]
        delta, deltaType := calculateDelta(currentAmount, prevAmount)

        results = append(results, model.CostData{
            Service:   service,
            Amount:    currentAmount,
            Delta:     delta,
            DeltaType: deltaType,
        })
    }

    return results, nil
}

func calculateDelta(current, previous float64) (float64, string) {
    if previous == 0 {
        if current == 0 {
            return 0, "neutral"
        }
        return 100, "increase"
    }

    delta := ((current - previous) / previous) * 100

    if delta > 0 {
        return delta, "increase"
    } else if delta < 0 {
        return -delta, "decrease"
    }
    return 0, "neutral"
}
```

**Key Points**:
- Compares last calendar month to previous month
- Delta calculated as percentage change
- Delta type: "increase", "decrease", or "neutral"
- Uses Cost Explorer API with monthly granularity

#### 3.2 API Client (`webapp/src/octoClient.ts`)

**Pattern**: Type-safe API communication
```typescript
class OctoClient {
    private getBaseURL(): string {
        return window.basename?.replace(/\/$/, '') || '';
    }

    private headers(): Record<string, string> {
        return {
            'Content-Type': 'application/json',
        };
    }

    private async getJson<T>(response: Response, defaultValue: T): Promise<T> {
        try {
            const value = await response.json();
            return value || defaultValue;
        } catch {
            return defaultValue;
        }
    }

    async getAWSResources(): Promise<ResourceGroup[]> {
        const path = '/aws/resources';
        const response = await fetch(this.getBaseURL() + path, {
            method: 'GET',
            headers: this.headers(),
        });

        if (response.status !== 200) {
            return [];
        }

        return await this.getJson(response, []);
    }
}
```

**Best Practices**:
- Use `window.basename` for correct plugin URL routing
- Graceful error handling (return empty array on failure)
- Generic `getJson` for type-safe JSON parsing
- Headers set for JSON content type

#### 3.3 RHS Component Pattern (`webapp/src/components/awsRHS/awsResourcesRHS.tsx`)

**Pattern**: Data fetching with loading/error states
```typescript
const AWSResourcesRHS: React.FC = () => {
    const intl = useIntl();
    const [loading, setLoading] = useState(true);
    const [error, setError] = useState<string | null>(null);
    const [resources, setResources] = useState<ResourceGroup[]>([]);
    const [costs, setCosts] = useState<CostData[]>([]);

    useEffect(() => {
        loadData();
    }, []);

    const loadData = async () => {
        setLoading(true);
        setError(null);
        try {
            const [resourcesData, costsData] = await Promise.all([
                octoClient.getAWSResources(),
                octoClient.getAWSCosts(),
            ]);
            setResources(resourcesData);
            setCosts(costsData);
        } catch (err) {
            setError(intl.formatMessage({
                id: 'AWSExplorer.error.loadFailed',
                defaultMessage: 'Failed to load AWS data. Please check your credentials.',
            }));
        } finally {
            setLoading(false);
        }
    };

    if (loading) {
        return <div className='loading-spinner'>Loading AWS data...</div>;
    }

    if (error) {
        return (
            <div className='error-message'>
                <p>{error}</p>
                <button onClick={loadData}>Retry</button>
            </div>
        );
    }

    return (
        <div className='aws-resources-rhs'>
            <ResourceSection resources={resources} />
            <CostSection costs={costs} />
        </div>
    );
};
```

**Best Practices**:
- i18n with `react-intl` for all user-facing strings
- Parallel data fetching with `Promise.all`
- Clear loading and error states
- Retry button for failed requests

### 5. Error Handling Patterns

#### 5.1 Custom Error Types (`server/model/error.go`)

**Pattern**: Typed errors with HTTP status mapping
```go
type ErrBadRequest struct {
    reason string
}

func (e *ErrBadRequest) Error() string {
    return e.reason
}

func NewErrBadRequest(reason string) *ErrBadRequest {
    return &ErrBadRequest{reason: reason}
}

func IsErrBadRequest(err error) bool {
    var badRequest *ErrBadRequest
    return errors.As(err, &badRequest)
}
```

**Usage in API handler**:
```go
func (a *API) errorResponse(w http.ResponseWriter, r *http.Request, err error) {
    errorResponse := model.ErrorResponse{
        Error:     err.Error(),
        ErrorCode: http.StatusInternalServerError,
    }

    switch {
    case model.IsErrBadRequest(err):
        errorResponse.ErrorCode = http.StatusBadRequest
    case model.IsErrUnauthorized(err):
        errorResponse.ErrorCode = http.StatusUnauthorized
    case model.IsErrNotFound(err):
        errorResponse.ErrorCode = http.StatusNotFound
    default:
        errorResponse.Error = "internal server error"
        errorResponse.ErrorCode = http.StatusInternalServerError
    }

    // Log and return
    a.plugin.logger.Warn("api error response",
        mlog.Int("code", errorResponse.ErrorCode),
        mlog.Err(err),
        mlog.String("api", r.URL.Path),
    )

    setResponseHeader(w, "Content-Type", "application/json")
    data, _ := json.Marshal(errorResponse)
    w.WriteHeader(errorResponse.ErrorCode)
    w.Write(data)
}
```

## Common Pitfalls and Solutions

### 1. Secret Key Display Issue

**Problem**: Secret key displayed in plaintext after save.

**Solution**: Use `placeholder` field in settings schema:
```json
{
    "key": "AWSSecretAccessKey",
    "type": "text",
    "placeholder": "••••••••••••••••"
}
```

### 2. TypeScript Type Mismatches

**Problem**: JSON serialization differences between Go and TypeScript.

**Solution**: Keep field names consistent:
```go
type Resource struct {
    ID      string                 `json:"id"`
    Type    string                 `json:"type"`
    State   string                 `json:"state,omitempty"`
    Details map[string]interface{} `json:"details,omitempty"`
}
```

```typescript
export interface Resource {
    id: string;
    type: string;
    state?: string;
    details?: Record<string, any>;
}
```

### 3. CORS Issues

**Problem**: Frontend cannot connect to plugin API.

**Solution**: Use `window.basename` for correct base URL:
```typescript
private getBaseURL(): string {
    return window.basename?.replace(/\/$/, '') || '';
}
```

### 4. AWS API Rate Limiting

**Problem**: Concurrent requests to multiple AWS services hit rate limits.

**Solution**: Implement throttling or sequential fetching:
```go
func (c *Client) GetAllResources() ([]model.ResourceGroup, error) {
    var groups []model.ResourceGroup

    // Fetch sequentially to avoid rate limiting
    ec2Instances, _ := c.GetEC2Instances()
    // ... process
    time.Sleep(100 * time.Millisecond)

    s3Buckets, _ := c.GetS3Buckets()
    // ... process
}
```

### 5. Time Zone Issues in Cost Calculation

**Problem**: Cost month boundaries incorrect due to timezone.

**Solution**: Always use UTC:
```go
now := time.Now().UTC()
lastMonthStart := time.Date(now.Year(), now.Month()-1, 1, 0, 0, 0, 0, time.UTC)
```

### 6. Build Failures on Different Platforms

**Problem**: Binaries not executable due to missing build tags.

**Solution**: Ensure all 5 platforms built in Makefile:
- linux-amd64
- linux-arm64
- darwin-amd64
- darwin-arm64
- windows-amd64

### 7. Hot Reload Not Working

**Problem**: Changes not reflected in development.

**Solution**: Use `make watch` which:
- Builds server with correct output paths
- Runs webpack in watch mode
- Copies to correct plugin location

### 8. Missing IAM Permissions

**Problem**: AWS API calls fail with access denied.

**Solution**: Ensure IAM policy includes:
```json
{
    "Version": "2012-10-17",
    "Statement": [
        {"Effect": "Allow", "Action": ["sts:GetCallerIdentity"], "Resource": "*"},
        {"Effect": "Allow", "Action": ["ce:GetCostAndUsage"], "Resource": "*"},
        {"Effect": "Allow", "Action": ["ec2:Describe*"], "Resource": "*"},
        {"Effect": "Allow", "Action": ["s3:ListAllMyBuckets", "s3:GetBucketLocation"], "Resource": "*"},
        {"Effect": "Allow", "Action": ["lambda:ListFunctions"], "Resource": "*"},
        {"Effect": "Allow", "Action": ["rds:DescribeDBInstances"], "Resource": "*"},
        {"Effect": "Allow", "Action": ["elasticfilesystem:DescribeFileSystems"], "Resource": "*"},
        {"Effect": "Allow", "Action": ["elasticloadbalancing:Describe*"], "Resource": "*"},
        {"Effect": "Allow", "Action": ["ecs:List*", "ecs:Describe*"], "Resource": "*"}
    ]
}
```
