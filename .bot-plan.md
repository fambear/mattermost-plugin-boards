# IT-581: File Attachment Blocks for Cards (PDF Preview + Generic Files)

## Overview

This plan implements two new content block types for Boards cards:
1. **PDF File Block** (`file-pdf`) - PDF documents with first-page preview
2. **Generic File Block** (`file-generic`) - Universal block for all other non-media files

### Content Registration Pattern

```typescript
// filePdfElement.tsx
contentRegistry.registerContentType({
    type: 'file-pdf',
    getDisplayText: (intl) => intl.formatMessage({id: 'ContentBlock.file-pdf', defaultMessage: 'PDF file'}),
    getIcon: () => <CompassIcon icon='file-pdf-outline-large'/>,
    createBlock: async (boardId, intl) => {
        return new Promise<FilePdfBlock>((resolve) => {
            Utils.selectLocalFile(async (file) => {
                const fileId = await octoClient.uploadFile(boardId, file)
                if (fileId) {
                    const block = createFilePdfBlock()
                    block.fields.fileId = fileId
                    block.fields.fileName = file.name
                    block.fields.fileSize = file.size
                    block.fields.mimeType = file.type
                    resolve(block)
                }
            }, '.pdf')
        })
    },
    createComponent: (block, readonly) => <FilePdfElement block={block} readonly={readonly}/>,
})
```

### Drag-Drop File Type Routing

Modify `imagePaste.tsx` to route files appropriately:
```typescript
const uploadItems = useCallback(async (items: FileList) => {
    for (const item of items) {
        const file = item
        const ext = file.name.split('.').pop()?.toLowerCase()
        const mimeType = file.type

        // Route by type
        if (mimeType.startsWith('image/')) {
            // Create image block (existing)
        } else if (mimeType.startsWith('video/') || VIDEO_TYPES.includes(ext)) {
            // Create video block (existing)
        } else if (ext === 'pdf' || mimeType === 'application/pdf') {
            // Create file-pdf block (new)
        } else {
            // Create file-generic block (new)
        }
    }
}, [])
```

## Potential Pitfalls & Edge Cases

1. **PDF.js Worker Setup**
   - Need to configure worker path correctly for both dev and production
   - Consider using CDN or bundling worker

2. **Large PDF Files**
   - Loading entire PDF for preview can be slow
   - Consider lazy loading previews only when block is visible
   - Use `MediaLoader` component pattern from existing elements

3. **File Name Truncation**
   - Long file names need to be truncated (see `attachmentElement.tsx:112-119`)

4. **Error Handling**
   - Failed uploads should show flash message
   - Failed preview loads should show error state with retry option
   - Use existing `MediaLoader` component for loading/error states

5. **Existing Image/Video Handling**
   - Must NOT break existing drag-drop for images and videos
   - Carefully test the routing logic in `imagePaste.tsx`

6. **PDF Page Count**
   - Can be extracted client-side using pdf.js
   - Server-side extraction is optional (skip for v1)

7. **MIME Type Detection**
   - File.type may be empty or incorrect in some browsers
   - Fall back to extension-based detection

8. **Download Behavior**
   - Use `getFileAsDataUrl` to fetch file
   - Create anchor element with `download` attribute
