## Issues Found

### Issue 1: Jest Mock Failures for octoClient (CRITICAL)

**Error:**
```
TypeError: mockedOcto.getFileAsDataUrl.mockResolvedValue is not a function
```

**Location:**
- `webapp/src/components/content/filePdfElement.test.tsx:95`
- `webapp/src/components/content/fileGenericElement.test.tsx:45`

**Root Cause:**
The tests use `jest.mock('../../octoClient')` at the top of the file, but when run through `@swc/jest` transformer, the mock is not being properly hoisted/applied. This affects ALL tests that mock octoClient, not just the new file block tests (same issue exists in imageElement.test.tsx and videoElement.test.tsx).

**Evidence:**
- Tests that don't mock octoClient (dividerElement.test.tsx, checkboxElement.test.tsx) pass fine
- Tests that mock octoClient (imageElement, videoElement, filePdfElement, fileGenericElement) all fail with the same error

**Fix Options:**

**Option A: Create a manual mock for octoClient (RECOMMENDED)**
Create `webapp/__mocks__/octoClient.ts`:
```typescript
export default {
    getFileAsDataUrl: jest.fn().mockResolvedValue({ url: '' }),
    getFileInfo: jest.fn().mockResolvedValue({}),
    uploadFile: jest.fn().mockResolvedValue(''),
    // Add other methods as needed
};
```

**Option B: Update tests to use `jest.doMock` instead of `jest.mock`**
This requires restructuring the tests, which is more invasive.

**Option C: Fix the SWC/Jest configuration for proper mock hoisting**
This may have side effects on other tests.

### Issue 2: Test Files Need Manual OctoClient Mock Reset

The tests correctly clear mocks in `beforeEach`, but the initial mock needs to be set up properly. The current pattern:
```typescript
jest.mock('../../octoClient')
const mockedOcto = mocked(octoClient, true)
```

This pattern works in other projects but fails here due to SWC transformer behavior.
